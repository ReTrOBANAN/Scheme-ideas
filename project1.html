01 / ЭЛЕКТРОНИКА

Система мониторинга давления на ESP32

Игрушка на базе ESP32, которая считывает касания ребёнка с датчиков давления, смешивает цвета на RGB-ленте и передаёт полученные данные в мобильное приложение по Bluetooth.

ESP32 FSR BLE
Подробнее о проекте

Датчики FSR изменяют своё сопротивление под действием давления. ESP32 считывает их показания и передаёт данные через Bluetooth Low Energy (BLE) в мобильное приложение. Это позволяет получать информацию об активности ребёнка.

02 / COMPUTER VISION

Распознавание волейбольного мяча с помощью ИИ

Проект компьютерного зрения для автоматического обнаружения волейбольного мяча на видеозаписях матчей с использованием нейросети.

YOLOv7 Roboflow Computer Vision
Подробнее о проекте

В основе проекта лежит модель обнаружения объектов YOLOv7. Для работы с данными использовался Roboflow. Нейросеть анализирует кадры видеозаписи и определяет расположение волейбольного мяча. Проект объединяет машинное обучение и спортивную аналитику.

03 / WEB DEVELOPMENT

Школьный форум вопросов и ответов

Веб-платформа для школьников, где можно задавать вопросы, делиться знаниями и помогать другим учащимся находить ответы.

Frontend Backend Web
Подробнее о проекте

Форум создан для общения и взаимопомощи школьников. Пользователи могут публиковать свои вопросы и отвечать на вопросы других участников. Основная идея проекта — создать удобное пространство для обмена знаниями и обсуждения школьных тем.
